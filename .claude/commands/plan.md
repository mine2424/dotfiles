Analyze the current codebase and create an implementation plan for the requested change.

## Steps

1. Read relevant files to understand the current architecture and patterns
2. Identify all files that need to be created, modified, or deleted
3. Assess risks: breaking changes, migrations, performance impact
4. Create a step-by-step implementation plan where each step is independently verifiable
5. Present the plan and **wait for user approval before making any changes**

## Rules

- Reuse existing patterns, utilities, and abstractions found in the codebase
- Prefer the simplest approach that meets requirements
- Flag assumptions that need confirmation
- Do not start implementation until the plan is explicitly approved

# 共通開発ルール（採用済みの初期内容・設定用の例）

- 現段階に必要な最小限を実装し、不要な抽象化・依存・設定・ファイル分割を増やさない。
- コード内に日本語コメントを付け、関数の役割と重要な判断理由を説明する。

- ルールや必須の検証を、実装の都合で黙って弱めない。競合や不足は本人に確認する。
- 認証・課金・外部送信・公開は許可された範囲に限定し、別課金へ無断で切り替えない。

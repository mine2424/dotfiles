# Fix

グローバルAGENTSと同じagentディレクトリのPRINCIPLES.mdを読む。
pstackのpoteto-mode本体を読み、bug-fix / runtime-forensics / perf-issue等から状況に合うPlaybookを選ぶ。

利用者への影響、現在の挙動と期待する挙動、再現条件、最初に壊れる境界を確認する。
本番停止やデータ変更が必要なら、ローカルでの修正とは区別し、対象・影響・必要な許可を示す。
緊急の緩和策と根本修正を混同しない。安全な既存環境・fixtureで再現し、秘密を含むログを複製しない。

tddや既存の回帰ハーネスで修正前の失敗と修正後の成功を確かめる。再現できない時は仮説と観測不足を明記する。
調査結果に応じて実験・修正・再現へ戻り、手順を消化するための編集は行わない。
Ponytailで最小修正を保ち、必要なエラー処理や診断を削らない。復旧・回帰防止・未解決を分けて報告する。
